## 一、模块定位

健康咨询是智能问诊系统的核心模块之一，用户通过自然语言描述自身症状或健康疑问，系统调用大模型（DeepSeek）生成结构化、可读性强的健康解答，帮助用户初步了解症状、获取缓解建议并明确就医时机。

该模块全程强调**"仅供参考、及时就医"的免责边界**，不提供诊断结论，不替代专业医疗服务。

---

## 二、功能描述

### 1. 对话问答

- 用户在输入框输入健康问题（如"牙疼怎么办"），点击发送按钮或按 Enter 提交。
- 系统调用 AI 服务生成回答，并以**流式输出**方式逐段展示，降低用户等待焦虑。
- 回答内容支持 **Markdown 渲染**，包括标题、加粗、列表、表格、emoji 等。

### 2. 输入交互

- 输入框展示占位提示文案，引导用户描述症状。
- 支持 **Enter 发送**、**Shift+Enter 换行**。
- 发送成功后输入框清空，用户消息进入对话流；AI 回复过程中禁用发送，防止重复提交。

### 3. 会话管理

- **欢迎引导**：进入页面或清空会话后，展示 AI 助手能力说明与免责提示。
- **清空对话**：点击"清空"按钮重置会话并回到欢迎语状态。
- **上下文连贯**：同一会话内保留多轮上下文，AI 可结合历史对话作答。

### 4. 合规与免责

- 页面底部固定展示：**"智能问诊系统 v1.0 | 仅供健康咨询使用，不替代专业医疗建议"**。
- 每次 AI 回复末尾附带就医建议与免责提示。

---

## 三、AI 输出要求

AI 对健康咨询类问题的回答必须结构化、完整，至少包含以下五个部分，**缺一不可**：

| 部分 | 内容要求 | 示例 |
|---|---|---|
| 症状分析 | 对用户描述的症状进行简明解析，说明可能原因（非诊断） | "牙痛可能由龋齿、牙龈炎或智齿引起" |
| 缓解建议 | 给出可操作、无风险的护理/生活建议 | "冷敷面颊、避免刺激性食物、避免用患侧咀嚼" |
| 需警惕事项 | 明确列出"不建议做"的危险行为 | "不要自行服用抗生素、不要用偏方止疼" |
| 何时就医 | 给出分级就医时机，含时间阈值与伴随症状 | "持续 1–2 天未缓解应就诊；伴发热/出血应尽快就医" |
| 温馨提示 | 附免责声明，强调仅供参考 | "以上建议仅供参考，请以专业医生诊断为准" |

**输出约束：**

- 语言通俗、分点清晰，避免堆砌专业术语。
- 不给出明确疾病诊断结论，不推荐具体处方药。
- 涉及急危重症（胸痛、呼吸困难、大出血、意识障碍等）时，**优先且醒目**提示"请立即拨打急救电话或就近就医"，再补充其他说明。
- 回答内容需通过 Markdown 渲染正确显示，流式过程中不得出现标签错乱或半截结构。

> 实现说明：五段式结构通过 System Prompt 约束 DeepSeek 输出；提示词模板在阶段 3《开发文档》中设计。

## 四、业务规则

| 编号 | 规则 | 说明 |
|---|---|---|
| BR-01 | 输入校验 | 空内容（纯空格）不允许发送，需提示用户并聚焦输入框 |
| BR-02 | 长度限制 | 单次输入限制最大长度（2000 字符），超长需提示或截断 |
| BR-03 | 流式渲染 | AI 回复必须流式返回，并正确解析 Markdown，避免标签错乱 |
| BR-04 | 结构完整性 | 回答须包含"症状分析/缓解建议/需警惕事项/何时就医/温馨提示"，缺失视为异常 |
| BR-05 | 免责强制 | 任何回答均须附带就医建议与免责声明，不得遗漏 |
| BR-06 | 会话隔离 | 清空对话后上下文同步重置，不残留历史记录 |
| BR-07 | 医疗边界 | 急危重症优先提示"立即就医"，不得仅提供建议 |
| BR-08 | 防重复提交 | AI 回复进行中禁用发送，避免并发请求导致上下文错乱 |
| BR-09 | 故障降级 | 网络异常、接口超时或服务错误时返回友好提示，不中断会话，允许重试 |

## 五、异常场景

| 场景 | 触发条件 | 预期处理 |
|---|---|---|
| E1 空输入 | 发送空串/纯空格 | 拒绝发送，提示并聚焦输入框 |
| E2 超长输入 | 输入超过长度上限 | 限制输入或截断并提示 |
| E3 请求失败 | 网络异常/服务 5xx | 返回"服务暂时不可用，请稍后重试"，保留会话 |
| E4 流式中断 | 流式响应中途断开 | 保留已返回部分，提示"回复中断，请重试"，不出现半截 Markdown |
| E5 接口超时 | 响应超时 | 终止本次请求，提示超时，允许重发 |
| E6 无关/违规输入 | 与医疗无关或含违规内容 | 引导回归健康咨询主题，不做无关回答 |
| E7 急危重症输入 | 胸痛/呼吸困难/大出血/意识丧失等 | 优先返回"立即拨打急救电话或就近就医"提示 |
| E8 重复提交 | 上一次请求未完成时再次发送 | 禁用发送按钮/加 loading 态，阻止重复请求 |
| E9 清空误操作 | 用户点击清空 | 二次确认，避免误删历史对话 |
