## 1. 项目概述

### 1.1 项目背景

普通人面对身体不适时往往缺乏医学知识，难以判断是否需要就医；拿到体检报告后，也常被专业术语和指标缩写困扰。本项目构建一个面向普通用户的智能问诊系统，借助 DeepSeek 大模型的医学知识理解与语言表达能力，提供健康咨询问答和体检报告智能分析两大核心服务。

### 1.2 项目目标

1. 用户可以像"聊天"一样进行多轮健康咨询，获得通俗、有条理的健康建议。
2. 用户上传体检报告 PDF，系统自动解析内容并由 AI 生成结构化分析报告（异常指标解读、总体评估、就医建议）。
3. 提供问诊/分析历史记录，用户可随时回看。
4. 全流程明确"非医疗诊断"边界，避免误导。

### 1.3 系统边界与定位

- 系统是**健康信息助手**，不是互联网医院，**不提供疾病诊断、处方开具、用药指导剂量**等医疗行为。
- 所有 AI 输出需附带免责声明，异常或危急情况应建议用户及时就医。

### 1.4 用户角色

| 角色 | 说明 |
|------|------|
| 普通用户 | 系统唯一角色。进行健康咨询、上传体检报告、查看分析结果与历史记录。 |

> 本期不包含医生端、管理员端；管理后台如运营需要作为二期扩展。

### 2.2 FR-1 / FR-2 健康咨询

**功能描述**：用户以对话方式描述症状或健康问题，系统调用 DeepSeek 大模型，以流式方式返回结构化健康建议。

> 本模块已细化为独立规格文档：**《健康咨询模块需求.md》**（含功能描述、AI 输出五段式要求、业务规则 BR-01～BR-09、异常场景 E1～E9），以下为要点摘录。

**需求要点**：

1. 输入：文本问题，长度 1～2000 字；输入框带占位引导文案；Enter 发送、Shift+Enter 换行。
2. 对话形式：用户与 AI 消息气泡式呈现，按时间顺序排列；AI 回复**流式输出**（逐段打字机效果），首字响应 ≤5s。
3. **Markdown 渲染**：回答支持标题、加粗、列表、表格、emoji；流式过程中不得出现标签错乱或半截结构。
4. 多轮上下文：请求 AI 时携带本次会话的历史消息，保证回答连贯；上下文过长时系统自动截断（保留最近 N 轮）。
5. 会话管理：进入页面或清空会话后展示**欢迎引导**（能力说明+免责提示）；"清空"按钮重置会话并回到欢迎语（清空前二次确认）；AI 回复过程中禁用发送，防重复提交。
6. AI 输出结构（FR-12）：回答必须包含**症状分析、缓解建议、需警惕事项、何时就医、温馨提示**五个部分，缺一不可；不给出明确诊断结论、不推荐具体处方药。
7. 安全边界：急危重症（胸痛、呼吸困难、大出血、意识障碍等）优先且醒目提示"立即拨打急救电话或就近就医"；与医疗无关或违规输入引导回归健康咨询主题。
8. 免责：页面底部固定展示"智能问诊系统 v1.0 | 仅供健康咨询使用，不替代专业医疗建议"；每次 AI 回复末尾附带就医建议与免责提示。

### 2.3 FR-3 / FR-4 体检报告上传

> 本模块已细化为独立规格文档：**《体检报告分析模块PRD.md》**（含功能列表、业务规则 BR-01～BR-10、异常场景 E1～E9、验收标准、非功能性需求），以下为要点摘录。

**功能描述**：用户通过上传区提交体检报告 PDF。

**交互要求（已确认）**：

1. 上传区支持**点击**或**拖拽** PDF 文件到上传区两种方式，展示引导文案并提供**"选择文件"按钮**。
2. 仅支持 `.pdf` 格式；文件类型不符时拒绝上传并提示："仅支持 PDF 格式"。
3. 文件大小 ≤10MB；超限时拒绝并提示："文件大小不能超过 10MB"。
4. **空文件（0 字节）校验**：拦截并提示"文件无效，请重新选择"。
5. 上传中显示进度/加载状态；上传成功显示文件名、大小，并自动进入解析分析流程。
6. 一次仅上传一个报告文件；未选择/拖放文件时给出提示。
7. 校验须同时在前端（即时反馈）与后端（安全兜底）执行，错误文案保持一致。

### 2.4 FR-5 / FR-6 / FR-7 报告解析与分析

**功能描述**：系统提取 PDF 文本，交由 DeepSeek 生成结构化分析结果。

**处理流程**：

```
上传 PDF → 文件校验 → 文本提取 → 内容有效性检查 → 组装提示词 → 调用 DeepSeek → 生成结构化报告 → 存储并展示
```

**需求要点**：

1. 文本提取：对文本型 PDF 使用解析库直接提取文字；扫描件（图片型 PDF）识别不到文字时，提示用户"报告内容无法识别，请上传清晰 PDF"，允许重试（OCR 作为二期扩展项）。
2. 提取文本为空或过短（如 <50 字）时判定为解析失败，提示用户。
3. 解析期间展示加载状态"AI 正在分析体检报告，请稍候…"，并禁用上传/分析等操作防止并发提交；分析中断时终止本次解析，不残留半成品结果。
4. AI 分析输出为**四段式结构（缺一不可）**：
   - **基本信息**：报告日期、体检机构、姓名、性别、年龄等；
   - **异常项明细**：逐条列出异常指标，含检测值、参考范围、异常状态（⚠️ 偏高/偏低）、针对该指标的改进方案——不得只给结论；
   - **总体健康建议**：汇总性建议，给出整体健康改善方向；
   - **注意事项**：需特别留意的风险项与就医提醒。
5. 分析结果以结构化页面展示（表格/卡片，偏高/偏低颜色区分），而非纯文本段落。
6. **急危指标提醒**：检出严重异常指标（如肿瘤标志物显著升高）时，醒目提示"建议尽快就医"，并保留完整分析。
7. **结果操作（FR-13）**：支持"下载报告"（导出分析结果，失败可重试）与"重新分析"（清空当前结果，更换报告再次解析）。
8. 分析耗时较长时（大模型生成），界面必须有加载态与超时机制（默认 120s 超时）；解析失败返回友好提示，允许重新上传或重试。
9. **隐私保护**：报告内容仅用于本次分析，默认不落盘留存原始文件；如留存须明确告知存储策略。

### 2.5 FR-8 / FR-9 历史记录

**功能描述**：保存用户的咨询会话与报告分析记录，支持回看。

**需求要点**：

1. 咨询历史：按会话列表展示（标题取首个问题摘要 + 时间），点击进入查看完整对话。
2. 分析历史：列表展示（文件名、分析时间、总体结论摘要），点击查看完整分析报告。
3. 支持删除历史记录（删除前二次确认）。
4. 历史数据归属登录用户，仅本人可见（V1.1 变化，详见《历史记录查看功能需求.md》）；未登录访问历史记录跳转登录页。

### 2.6 FR-10 / FR-11 通用要求

1. 免责声明：页面底部固定展示"智能问诊系统 v1.0 | 仅供健康咨询使用，不替代专业医疗建议"；咨询每次 AI 回复末尾与分析结果区域均附免责与就医提示。
2. 错误提示场景全覆盖：
   - 文件格式/大小不符；
   - PDF 加密无法打开；
   - 文本提取失败/内容为空；
   - DeepSeek API 调用失败、超时、限流；
   - 网络异常。
3. 错误提示使用友好中文文案，不向用户暴露技术堆栈信息。

### 2.7 FR-15 ～ FR-18 用户认证与登录态历史（V1.1 新增）

> 详细规则见专项文档：《用户注册功能需求.md》《用户登录功能需求.md》《历史记录查看功能需求.md》。

1. 注册：用户名 3~20 位（字母/数字/下划线，唯一）、密码 6~20 位并二次确认、邮箱格式校验且唯一；异常文案："用户名已存在"/"邮箱已被注册"/"密码不一致，请重新输入"/具体格式错误；注册成功跳转登录页。
2. 登录：用户名+密码匹配成功进入主页面并维持登录态（服务端会话/Token）；失败统一提示"用户名或密码错误"（防账号枚举）。
3. 退出登录：清除登录态回登录页；数据仅本人可见。
4. 历史记录：登录后可见，咨询会话/报告分析双 Tab、时间倒序、点击回看、删除二次确认、空态"暂无历史记录"。
5. 密码加盐哈希存储，接口与日志不落明文。

## 3. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 普通咨询流式输出，首字响应 ≤5s；报告分析整体 ≤120s |
| 可用性 | 界面简洁，医学小白可无指导上手；适配主流浏览器（Chrome/Edge） |
| 安全 | API Key 仅存于后端环境变量，禁止写入前端与代码仓库；上传文件类型白名单校验；防路径穿越；用户密码加盐哈希存储，凭证校验数据归属防越权 |
| 数据隐私 | 健康数据属敏感个人信息：报告内容仅用于本次分析，默认不落盘留存原始 PDF；如留存须明确告知存储策略（模块 PRD BR-09）；页面展示隐私说明 |
| 可维护性 | 前后端分离、分层清晰；DeepSeek 调用封装为独立模块，便于更换模型 |
| 合规 | 明确 AI 非诊断定位；危急症状（如胸痛、昏迷）回答必须优先引导拨打急救/就医 |

## 5. 核心业务流程

### 5.1 健康咨询流程

```
用户进入咨询页 → 输入问题 → 后端组装上下文调用 DeepSeek → 返回建议 → 展示（附免责声明）→ 用户追问（多轮）
```

### 5.2 体检报告分析流程

```
进入报告分析页 → 点击/拖拽上传 PDF → 前端校验（格式/大小）→ 后端校验 → 文本提取
→ 提取成功 → 调用 DeepSeek 结构化分析 → 展示分析报告 → 保存历史记录
→ 提取失败/不合规文件 → 对应错误提示 → 允许重新上传
```

## 7. 验收标准（整体）

1. 用户可完成多轮健康咨询，回答连贯且带免责声明。
2. 上传合法 PDF（≤10MB）可在 120s 内得到结构化分析报告。
3. 上传非 PDF 或 >10MB 文件被拦截，提示准确文案。
4. 咨询与分析历史可回看、可删除。
5. AI 服务异常时系统不崩溃，给出友好提示。
