# 历史记录查看功能 — 需求描述

| 文档版本 | V1.0 |
|----------|------|
| 编写日期 | 2026-10-18 |
| 关联文档 | 《用户登录功能需求.md》《PRD.md》FR-8/FR-9/FR-14、《用户故事.md》US-401~403 |
| 页面形态 | 主页面内的"历史记录"入口或独立页面（阶段 2 原型时确定，本阶段只定需求） |

## 一、核心规则

1. **仅登录后可见**：未登录访问历史记录 → 跳转登录页。
2. 用户只能查看**自己的**历史数据（数据归属由"浏览器标识 client_id"升级为"登录用户"——该变化涉及数据库与接口的对应调整，待阶段 3 更新《数据库设计.md》《API设计文档.md》时落实）。
3. 记录分**两类，Tab 切换**：
   - **咨询会话**：列表项显示会话标题（首问摘要）+ 时间；点击回看完整多轮对话；
   - **报告分析**：列表项显示文件名、异常项数量、分析时间；点击回看完整四段式分析报告。
4. 两类列表均按**时间倒序**排列（最新在前）。
5. 支持删除记录：沿用 PRD FR-14，**删除前二次确认**，确认后不可恢复。

## 二、异常/边界场景

| 场景 | 预期表现 |
|------|----------|
| 该用户没有任何记录 | 空态提示"暂无历史记录" |
| 未登录直接访问 | 跳转登录页 |
| 删除他人记录（越权请求） | 拒绝并提示记录不存在（后端按归属校验，防篡改） |
| 登录态过期后继续操作 | 提示重新登录，回到登录页 |

## 三、验收要点

1. 用户 A 登录后只能看到 A 的会话与分析记录；用户 B 登录互不可见。
2. 完成一次咨询、一次报告分析后，对应新记录分别出现在两个 Tab，时间倒序第一条即最新。
3. 点击咨询记录可完整回看多轮对话；点击分析记录可完整回看四段式报告（含免责声明展示）。
4. 删除记录弹出二次确认：确认后列表移除且不可恢复，取消后无变化。
5. 清空所有记录后，Tab 显示"暂无历史记录"空态。
