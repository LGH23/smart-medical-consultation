## Epic 1：健康咨询对话

### US-101 发起健康咨询（P0）

**作为** 普通用户，**我希望** 在对话框中输入我的症状或健康问题并发送，**以便** 快速获得 AI 的健康建议。

**验收标准：**
1. 输入框展示占位引导文案；可输入 1～2000 字的文本；空内容或纯空格时拒绝发送，提示并聚焦输入框（BR-01/E1）；超长时限制输入或截断并提示（BR-02/E2）。
2. 按 Enter 发送消息，Shift+Enter 换行；发送成功后输入框清空。
3. 发送后我的消息立即以气泡形式显示在对话区右侧。
4. AI 回复期间显示加载状态，且发送按钮禁用、回复完成后恢复，防止重复提交（BR-08/E8）。

### US-102 获得流式输出、Markdown 排版的良好回答（P0）

**作为** 普通用户，**我希望** AI 用通俗语言流式回答我的问题，并以清晰的 Markdown 排版展示，**以便** 少等待、易阅读。

**验收标准：**
1. AI 回复流式输出（打字机效果），首字响应 ≤5s。
2. 回复支持 Markdown 渲染：标题、加粗、列表、表格、emoji 均正确显示；流式过程中无标签错乱或半截结构（BR-03/E4）。
3. 流式中断时保留已返回部分并提示"回复中断，请重试"；请求失败/超时返回友好提示且不中断会话（E3/E5、BR-09）。
4. 页面底部固定展示："智能问诊系统 v1.0 | 仅供健康咨询使用，不替代专业医疗建议"；每次回复末尾附带就医建议与免责提示（BR-05）。
5. 提问涉及确诊、处方药时，AI 引导就医而非给出确定结论。

### US-103 多轮连续追问（P0）

**作为** 普通用户，**我希望** 在一次会话中连续追问且 AI 记得前文，**以便** 像真实问诊一样逐步深入。

**验收标准：**
1. 第二次及以后的提问，AI 回答能正确引用本会话先前内容（如"您刚才提到的头痛…"）。
2. 对话消息按时间顺序完整展示，可向上滚动查看历史消息。

### US-104 欢迎引导与清空对话（P0）

**作为** 普通用户，**我希望** 进入页面看到助手能力说明，并能一键清空对话回到初始状态，**以便** 随时开始新话题。

**验收标准：**
1. 进入页面或清空会话后，展示欢迎引导（AI 助手能力说明 + 免责提示）。
2. 点击"清空"按钮先弹出二次确认，确认后对话重置（E9）。
3. 清空后多轮上下文同步重置，AI 不再携带旧会话内容（BR-06）。

### US-105 危急症状得到就医引导（P0）

**作为** 普通用户，**我希望** 描述紧急症状（如剧烈胸痛、昏迷、大出血）时 AI 优先建议立即就医，**以便** 不耽误救治。

**验收标准：**
1. 输入危急症状关键词，AI 回复的首要且醒目的内容是拨打 120/立即就医的提示，再补充其他说明（BR-07/E7）。
2. 该行为由系统提示词保证，测试用例覆盖至少 3 类危急场景（胸痛、呼吸困难、大出血、意识障碍等）。

### US-106 AI 回答五段式结构完整（P0）

**作为** 普通用户，**我希望** 每次回答都包含"症状分析、缓解建议、需警惕事项、何时就医、温馨提示"五个部分，**以便** 全面了解情况、知道下一步该做什么。

**验收标准：**
1. 对典型咨询问题（如"牙疼怎么办"），回答完整包含五个部分，缺一不可（BR-04）。
2. "何时就医"部分包含时间阈值或伴随症状等分级时机描述。
3. "需警惕事项"明确列出不建议做的行为。
4. 回答不含明确疾病诊断结论、不推荐具体处方药。
5. 结构缺失时视为异常，可通过测试用例检出。

### US-107 无关或违规输入的引导（P1）

**作为** 普通用户，**我希望** 提了与医疗无关或违规的问题时，系统礼貌地把我引导回健康咨询主题，**以便** 明确系统能力边界。

**验收标准：**
1. 输入与医疗健康无关的问题（如写诗、闲聊八卦），AI 说明自身定位并引导回归健康咨询（E6）。
2. 输入违规内容，AI 拒绝回答且不产生不当输出。

## Epic 2：体检报告上传

### US-201 点击"选择文件"上传 PDF（P0）

**作为** 普通用户，**我希望** 点击"选择文件"按钮从电脑中选取体检报告 PDF，**以便** 提交分析。

**验收标准：**
1. 上传区展示"选择文件"按钮，点击后弹出系统文件选择框。
2. 文件选择框默认过滤为 PDF（accept=application/pdf）。
3. 选择成功后上传区显示文件名与大小，并自动进入分析流程。

### US-202 拖拽文件到上传区（P0）

**作为** 普通用户，**我希望** 直接把 PDF 文件拖到上传区完成上传，**以便** 操作更快捷。

**验收标准：**
1. 拖拽文件悬停于上传区时，上传区有高亮视觉反馈。
2. 松开后合法 PDF 正常进入分析流程，效果等同按钮选择。
3. 整个页面范围内拖入文件不会触发浏览器直接打开该文件。

### US-203 非 PDF 文件被拦截（P0）

**作为** 普通用户，**我希望** 上传了不支持的文件时系统立即提醒我，**以便** 换用正确格式。

**验收标准：**
1. 拖入或选择非 PDF（如 jpg、docx、xlsx、Word）时，拒绝上传。
2. 提示文案："仅支持 PDF 格式"。
3. 后端同样做 MIME/扩展名双重校验，绕过前端时后端返回明确错误，文案与前端一致。
4. 拦截后上传区恢复可再次操作状态。

### US-204 超大文件被拦截（P0）

**作为** 普通用户，**我希望** 超过 10MB 的文件被拒绝并提示，**以便** 了解限制去压缩或拆分报告。

**验收标准：**
1. 选择 >10MB 的 PDF 时，前端立即提示："文件大小不能超过 10MB"。
2. 后端二次校验，超限返回错误码与相同文案。
3. 恰好 10MB 的文件允许上传（边界值 ≤10MB）。

### US-205 空文件被拦截（P0）

**作为** 普通用户，**我希望** 上传了 0 字节的空文件时系统直接拦截，**以便** 不浪费时间去解析一个无效文件。

**验收标准：**
1. 上传 0 字节/空内容文件时，拒绝进入解析流程，提示："文件无效，请重新选择"（BR-03/E3）。
2. 前后端均校验，绕过前端时后端返回相同错误文案。
3. 拦截后允许重新选择文件。

## Epic 3：体检报告智能分析

### US-301 上传后自动解析并分析（P0）

**作为** 普通用户，**我希望** 上传报告后系统自动完成解析和 AI 分析，**以便** 无需任何额外操作。

**验收标准：**
1. 合法 PDF 上传后自动进入"解析中→分析中"流程，全程无需用户干预。
2. 解析期间页面展示加载状态文案："AI 正在分析体检报告，请稍候…"。
3. 解析过程中上传/分析等相关按钮禁用（置灰 + loading），解析中再次上传或点击分析被阻止（BR-04/E7）。
4. 从上传完成到结果展示 ≤120 秒；AI 接口异常/超时返回"报告解析失败，请重试"，允许重新上传（E4/BR-07）。
5. 解析过程网络中断时终止本次解析并提示重试，页面不残留半成品结果（E6）。

### US-302 查看四段式结构化分析结果（P0）

**作为** 普通用户，**我希望** 看到结构清晰的分析报告（基本信息、异常项明细、总体健康建议、注意事项），**以便** 快速知道哪些指标有问题、意味着什么、下一步该做什么。

**验收标准：**
1. 结果页完整包含四个部分，缺一不可（BR-05）：① 基本信息（报告日期、体检机构、姓名、性别、年龄等）；② 异常项明细；③ 总体健康建议；④ 注意事项（风险项与就医提醒）。
2. 每条异常项含四要素：检测值、参考范围、异常状态（⚠️ 偏高/偏低）、针对该指标的改进方案，不得只给结论（BR-06）。
3. 异常项以表格或卡片展示，偏高/偏低用 ⚠️ 标记与颜色区分。
4. 结果页附"仅供参考，不替代专业医疗建议"免责说明；页面底部固定展示系统版本与免责声明（BR-08）。

### US-303 对分析结果追问（P1）

**作为** 普通用户，**我希望** 针对报告分析结果继续提问（如"血脂偏高要紧吗"），**以便** 深入理解我的健康状况。

**验收标准：**
1. 分析完成后提供入口进入咨询对话，且携带该报告的分析摘要作为上下文。
2. AI 回答能结合报告内容。

### US-304 扫描件 PDF 的明确提示（P1）

**作为** 普通用户，**我希望** 上传扫描版 PDF 时系统告知无法解析的原因，**以便** 我改用其他方式。

**验收标准：**
1. 提取文本为空或过短（<50 字）、扫描件模糊或格式异常时，提示："报告内容无法识别，请上传清晰 PDF"，并允许重试（E5）。
2. 不进入 AI 分析，不产生无效历史记录。

### US-305 下载分析报告（P1）

**作为** 普通用户，**我希望** 将分析结果导出下载保存，**以便** 之后离线查看或分享给家人。

**验收标准：**
1. 分析完成后结果页提供"下载报告"入口，点击可成功导出分析结果文件。
2. 下载内容包含完整四段式结果与免责声明。
3. 导出过程网络异常等失败时，提示下载失败并允许重试下载（E8）。

### US-306 重新分析（P1）

**作为** 普通用户，**我希望** 一键清空当前结果并更换报告重新分析，**以便** 处理另一份体检报告。

**验收标准：**
1. 点击"重新分析"后当前结果清空，页面回到可上传状态。
2. 更换报告后可再次完整走通"上传→校验→解析→结果展示"流程。
3. 上一份报告的半成品/结果不残留、不串台。

### US-307 严重异常指标醒目提醒（P0）

**作为** 普通用户，**我希望** 报告检出严重异常指标（如肿瘤标志物显著升高）时结果页醒目提示就医，**以便** 不忽视潜在的重大健康风险。

**验收标准：**
1. 检出急危异常项时，结果页以醒目样式（高亮/警示色区块）展示"建议尽快就医"提示（BR-10/E9）。
2. 急危提醒不截断分析流程，完整四段式结果仍正常展示。
3. 提醒内容由 AI 按提示词规则输出，测试样例覆盖至少 1 类严重异常指标。

## Epic 4：历史记录管理

### US-401 查看咨询历史（P1）

**作为** 普通用户，**我希望** 在历史列表中看到过往咨询会话并点开回看，**以便** 回顾之前的建议。

**验收标准：**
1. 历史列表按时间倒序展示，每项含会话摘要标题与时间。
2. 点击后完整展示该会话的全部对话内容。

### US-402 查看报告分析历史（P1）

**作为** 普通用户，**我希望** 回看之前上传报告的分析结果，**以便** 对比或分享给家人。

**验收标准：**
1. 分析历史列表展示文件名、分析时间、总体评估摘要。
2. 点击后展示完整结构化分析报告。

### US-403 删除历史记录（P1）

**作为** 普通用户，**我希望** 删除不需要的历史记录，**以便** 保护我的健康隐私。

**验收标准：**
1. 每条历史有删除入口；点击后弹出二次确认。
2. 确认后该记录从列表消失且不可恢复；取消则无变化。

## Epic 5：异常与容错

### US-501 AI 服务异常时的友好提示（P0）

**作为** 普通用户，**我希望** DeepSeek 服务调用失败时看到友好提示，**以便** 知道稍后重试而不是以为系统坏了。

**验收标准：**
1. API 超时/报错/限流时，界面提示："AI 服务暂时不可用，请稍后重试"，不显示技术错误堆栈。
2. 咨询失败的消息支持一键重发。
3. 后端记录错误日志用于排查。

### US-502 加密/损坏 PDF 的处理（P1）

**作为** 普通用户，**我希望** 上传了加密或损坏的 PDF 时得到明确提示，**以便** 更换文件。

**验收标准：**
1. 无法打开的 PDF 返回提示："文件无法读取，可能已损坏或加密，请检查后重新上传"。
2. 流程终止，允许重新上传。

### US-503 网络中断的表现（P1）

**作为** 普通用户，**我希望** 上传过程中网络断开时有提示且系统可恢复，**以便** 重新操作。

**验收标准：**
1. 上传中断给出失败提示，页面可继续使用。
2. 不产生"半截"的脏历史记录。

### US-504 未选文件直接点击分析（P2）

**作为** 普通用户，**我希望** 没有选择文件时不会误触发分析流程。

**验收标准：**
1. 上传区无文件时，"分析"入口不可用或点击提示"请先选择要上传的文件"。

## Epic 6：用户认证与登录态历史（V1.1 新增）

### US-601 注册新账号（P0）

**作为** 新用户，**我希望** 用用户名、邮箱、密码注册账号，**以便** 使用系统并保存我的历史记录。

**验收标准：**
1. 用户名 3~20 位字母/数字/下划线、密码 6~20 位、邮箱格式正确，全部合法才可注册成功（异常场景见《用户注册功能需求.md》）。
2. 用户名重复 → 提示"用户名已存在"；邮箱重复 → 提示"邮箱已被注册"。
3. 两次密码不一致 → 提示"密码不一致，请重新输入"，且不会发起提交。
4. 注册成功后跳转到登录页面。
5. 绕过前端直调接口，后端执行同样校验并返回相同文案；数据库中密码为加盐哈希值，无明文。

### US-602 登录系统（P0）

**作为** 已注册用户，**我希望** 用用户名和密码登录，**以便** 进入主页面继续使用。

**验收标准：**
1. 匹配成功 → 返回成功并跳转主页面，登录态保持（刷新不丢）。
2. 用户名为空或密码为空 → 提示不能为空，不发起请求。
3. 账号不存在或密码错误，提示均为"用户名或密码错误"（不区分原因，防枚举）。
4. 登录页有"去注册"入口，点击跳注册页。

### US-603 退出登录（P1）

**作为** 已登录用户，**我希望** 主动退出登录，**以便** 在共用设备上不让他人看到我的数据。

**验收标准：**
1. 主页面有退出入口；点击后清除登录态并回到登录页。
2. 退出后直接访问历史记录 URL → 跳转登录页。

### US-604 查看本人历史记录（P0）

**作为** 已登录用户，**我希望** 查看自己的咨询会话与报告分析两类历史记录，**以便** 回顾过往健康信息。

**验收标准：**
1. 历史记录入口仅登录可见；含"咨询会话 / 报告分析"两个 Tab。
2. 两类列表均按时间倒序；咨询项显示标题+时间，报告项显示文件名+异常数+时间。
3. 点击条目可回看完整对话 / 完整四段式报告。
4. 用户 A 登录看不到用户 B 的任何记录（后端按归属校验）。
5. 无任何记录时显示"暂无历史记录"空态。

### US-605 删除历史记录的归属保护（P0）

**作为** 已登录用户，**我希望** 只能删除自己的记录且删除需确认，**以便** 隐私可控且不误删。

**验收标准：**
1. 删除前弹出二次确认；确认后不可恢复（沿用 FR-14/US-403）。
2. 携带他人记录 ID 的删除请求被拒绝（返回记录不存在）。

> 说明：E4（US-401～403）为无登录阶段的历史功能设定，V1.1 起由 E6 的 US-604/605 接管并升级归属规则，列表/回看/删除的交互要求继续有效。
