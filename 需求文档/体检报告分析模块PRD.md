## 一、模块定位

体检报告分析是智能问诊系统的另一核心模块。用户上传体检报告 PDF，系统调用 AI（DeepSeek）对报告内容进行结构化解析，输出**基本信息、异常项明细、健康建议与注意事项**，帮助用户快速读懂体检结果并明确后续行动。

该模块同样强调**"仅供参考、及时就医"的免责边界**，不提供诊断结论。

## 三、功能详细描述

### 3.1 报告上传（F-1）

- 用户通过**点击上传区**或**拖拽方式**上传体检报告文件，上传区展示引导文案与**「选择文件」按钮**。
- **文件类型限制**：仅支持 PDF 格式。
- **文件大小限制**：单份报告不超过 10MB。
- 一次仅上传一个报告文件；上传成功后展示文件名（含大小），自动进入解析流程。

### 3.2 文件校验（F-2）

| 校验项 | 规则 | 不通过提示 |
|--------|------|------------|
| 类型 | 仅 PDF（扩展名 + MIME 双重判断） | "仅支持 PDF 格式" |
| 大小 | ≤10MB | "文件大小不能超过 10MB" |
| 空文件 | 0 字节 / 空内容拦截 | "文件无效，请重新选择" |

校验在**前端即时执行**（快速反馈），**后端二次校验**（安全兜底），文案保持一致。

### 3.3 AI 解析报告（F-3）

- 上传后系统调用 AI 解析报告内容，期间展示加载状态：**"AI 正在分析体检报告，请稍候…"**。
- 解析过程中**禁用相关操作**（上传按钮、分析按钮置灰 + loading 态），防止重复提交与并发请求。
- 技术链路：PDF 文本提取 → 内容有效性检查 → 组装提示词调用 DeepSeek → 生成结构化结果。

### 3.4 分析结果展示（F-4）

AI 解析完成后，结构化输出以下**四个部分，缺一不可**：

| 部分 | 内容要求 |
|------|----------|
| 基本信息 | 报告日期、体检机构、姓名、性别、年龄等 |
| 异常项明细 | 逐条列出异常指标：检测值、参考范围、异常状态（如 ⚠️ 偏高/偏低）、**针对该指标的改进方案** |
| 总体健康建议 | 汇总性建议，给出整体健康改善方向 |
| 注意事项 | 需特别留意的风险项与就医提醒 |

展示要求：异常项以表格/卡片呈现，偏高/偏低用 ⚠️ 标记与颜色区分；不得只给结论而缺检测值与参考范围。

### 3.5 结果操作（F-5 / F-6）

- **下载报告**：将分析结果导出下载（文件格式与实现方式在阶段 3 开发文档确定），供用户保存。
- **重新分析**：清空当前结果与当前报告，回到上传区初始状态，支持更换报告再次解析。

### 3.6 合规与免责（F-7 / F-8）

- 分析结果附**"仅供参考，不替代专业医疗建议"**的免责说明。
- 页面底部固定展示系统版本与免责声明（与咨询页一致："智能问诊系统 v1.0 | 仅供健康咨询使用，不替代专业医疗建议"）。
- 检出**严重异常指标**（如肿瘤标志物显著升高等）时，醒目提示**"建议尽快就医"**，并保留完整分析结果。

## 四、业务规则

| 编号 | 规则 | 说明 |
|---|---|---|
| BR-01 | 文件类型校验 | 仅允许上传 PDF，其他格式（如 Word、图片）需拒绝并提示 |
| BR-02 | 文件大小校验 | 超过 10MB 需拒绝上传并提示，避免请求超时 |
| BR-03 | 空文件校验 | 空文件或 0 字节文件需拦截，提示"文件无效" |
| BR-04 | 解析状态管理 | 解析中展示加载态并禁用重复操作，防止并发请求 |
| BR-05 | 结果结构化 | 解析结果须包含基本信息、异常项明细、总体建议、注意事项四部分 |
| BR-06 | 异常项准确性 | 异常项需给出检测值、参考范围、异常状态，不得只给结论 |
| BR-07 | 解析失败降级 | 解析失败时返回友好错误提示，允许用户重新上传或重试 |
| BR-08 | 免责强制 | 分析结果须附带免责声明，强调不替代专业医疗建议 |
| BR-09 | 隐私保护 | 报告内容仅用于本次分析，不落盘或需明确告知存储策略 |
| BR-10 | 急危指标提醒 | 检出严重异常指标（如肿瘤标志物显著升高等）时，醒目提示及时就医 |

## 五、异常场景

| 场景 | 触发条件 | 预期处理 |
|---|---|---|
| E1 非 PDF 文件 | 上传 Word/图片等格式 | 拒绝上传，提示"仅支持 PDF 格式" |
| E2 文件超限 | 文件大于 10MB | 拒绝上传，提示"文件大小不能超过 10MB" |
| E3 空文件 | 上传 0 字节文件 | 拦截并提示"文件无效，请重新选择" |
| E4 解析失败 | AI 接口异常/超时/服务错误 | 返回"报告解析失败，请重试"，允许重新上传 |
| E5 报告无法识别 | 扫描件模糊/无文本/格式异常 | 提示"报告内容无法识别，请上传清晰 PDF"，允许重试 |
| E6 解析中断 | 解析过程网络中断 | 终止本次解析，提示重试，不残留半成品结果 |
| E7 重复提交 | 解析中再次上传/点击分析 | 禁用按钮，阻止并发请求 |
| E8 下载失败 | 导出结果时网络异常 | 提示下载失败，允许重试下载 |
| E9 严重异常指标 | 检出急危异常项 | 醒目提示"建议尽快就医"，并保留完整分析 |

## 六、验收标准

1. **上传校验**：拖拽/选择非 PDF 文件（jpg、docx 等）被拒绝并提示"仅支持 PDF 格式"；>10MB 的 PDF 被拒绝并提示"文件大小不能超过 10MB"；0 字节文件被拦截并提示"文件无效，请重新选择"；三项校验前后端均生效，绕过前端时后端返回相同错误文案。
2. **上传交互**：点击"选择文件"按钮可唤起系统文件选择框（默认过滤 PDF）；拖拽 PDF 到上传区有高亮反馈；恰好 10MB 的 PDF 允许上传（边界值 ≤10MB）；上传成功后展示文件名并自动进入解析流程。
3. **解析过程**：解析期间页面显示"AI 正在分析体检报告，请稍候…"加载态；上传/分析按钮置灰禁用，解析中再次触发上传或点击分析被阻止（E7）；从上传完成到结果展示 ≤120s，超时按解析失败处理。
4. **结果结构**：合法报告的解析结果完整包含基本信息、异常项明细、总体健康建议、注意事项四个部分（BR-05）；每条异常项含检测值、参考范围、⚠️ 偏高/偏低状态与该指标改进方案（BR-06）；缺失任一要素判定不通过。
5. **免责声明**：分析结果区域展示"仅供参考，不替代专业医疗建议"；页面底部固定展示系统版本与免责声明，任意页面滚动时可见（BR-08）。
6. **异常降级**：模拟 AI 接口异常/超时，返回"报告解析失败，请重试"且允许重新上传；上传无文本层扫描件，提示"报告内容无法识别，请上传清晰 PDF"；解析中中断网络，终止本次解析且页面不残留半成品结果（E4/E5/E6/BR-07）。
7. **结果操作**：点击"下载报告"成功导出分析结果文件；下载失败时提示并允许重试（E8）；点击"重新分析"后当前结果清空、回到可上传状态，更换报告可再次完整走通流程。
8. **急危提醒**：构造含严重异常指标（如肿瘤标志物显著升高）的报告样例，结果中醒目展示"建议尽快就医"提示，同时完整分析结果不缺失（BR-10/E9）。
9. **隐私保护**：报告内容仅用于本次分析；若系统留存数据，须在界面明确告知存储策略（BR-09）。

## 七、非功能性需求

| 类别 | 要求 |
|------|------|
| 性能 | 文件上传校验即时完成；AI 分析整体 ≤120s，超时终止并提示 |
| 安全 | API Key 仅存后端；上传类型白名单；文件名/路径安全处理，防路径穿越；限制单文件大小防资源耗尽 |
| 隐私 | 报告内容属敏感健康数据：默认解析完成即删原始文件，仅保留结构化分析结果；如留存原件须在 UI 告知策略（对应 BR-09） |
| 可用性 | 处理全程状态可视（上传成功→解析中→完成/失败）；失败均可重试，系统不崩溃 |
| 兼容性 | 主流浏览器 Chrome/Edge；不同排版的文本型体检报告 PDF 均可解析（扫描件除外，二期 OCR） |
| 可维护性 | PDF 提取与 AI 分析解耦，DeepSeek 调用封装为独立模块；结构化结果使用统一 Schema（阶段 3 定义） |
